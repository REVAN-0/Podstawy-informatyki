
# PYTANIE
* .1. Server -
 Nagłówek HTTP Server zawiera informacje o oprogramowaniu serwera, który obsługuje zapytanie. Pokazuje zazwyczaj nazwę i wersję serwera (np. gunicorn/1.19.0).

* 2. Request Method: GET -
Zapytanie o metodzie GET służy do pobierania danych z serwera. Jest to najczęściej stosowana metoda w HTTP, która umożliwia żądanie zasobów, takich jak strony internetowe czy pliki.
* 3. Status Code: 200 OK -* 
Status code 200 OK to odpowiedź HTTP, która oznacza, że żądanie zostało pomyślnie przetworzone przez serwer. Oznacza to, że dane zostały zwrócone prawidłowo. Taki status pojawia się np. podczas ładowania strony internetowej, kiedy serwer prawidłowo zwraca zawartość. To standardowy sposób potwierdzenia sukcesu żądania.
